# Reports

## Current Fit Validation Deliverable

- `Synthesis_Fit_Validation_Study.pdf` is the current Fit Analyzer validation
  report.
- `fit-validation/` contains the de-identified metrics, manifests, and
  checksums used to rebuild and audit that report.
- `build_reports.py` regenerates the current report and evidence snapshots.

Raw validation data, reviewer material, and pair-level outputs remain local
and gitignored under `scripts/validation/.artifacts/`.
