# Fit Validation Evidence Snapshots

This directory contains de-identified, repository-tracked summaries generated by:

```bash
npm run validate:pdf
```

The snapshots preserve the metrics, validation manifests, and checksums needed to
audit the published PDF without committing raw resumes, job descriptions, or
pair-level reviewer data. Raw study artifacts remain offline and gitignored under
`scripts/validation/.artifacts/`.

Do not edit the JSON snapshots by hand. Rebuild them from the current validation
artifacts and regenerate `reports/Synthesis_Fit_Validation_Study.pdf`.
